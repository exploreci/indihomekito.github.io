# IndiHome Kito – Landing Page

A simple landing page developed to present IndiHome internet services, available packages, and additional products.

## Overview

This project is a web-based landing page designed to provide visitors with information about IndiHome services, including internet packages, package benefits, pricing information, and registration options.

## Features

- Display of available internet packages.
- Presentation of package benefits and pricing.
- Call-to-action buttons for customer inquiries and registration.
- Information about additional products and services.
